# Окружения и передача

Разработка и тесты выполняются на dev-машине; небольшой сервер с панелью предназначен
для runtime. Конкретный сервер и его реквизиты в Git не хранятся. На этой итерации
SSH, перенос файлов, restart и deploy не выполняются.

Перед rollout:

1. Пользователь запускает tester и reviewer для переданного checkout/snapshot.
2. В отдельном тестовом магазине проверить создание карты, возврат в бота,
   уведомление, повтор уведомления и отмену. Проверить настройки чеков магазина.
3. На стенде с той же версией 3x-ui проверить создание inbound, продление активного
   и истёкшего доступа, limitIp и импорт ссылки. Адаптер classic API не объявляется
   совместимым со всеми версиями 3x-ui без этой проверки.
4. Подготовить секреты вне репозитория, HTTPS reverse proxy, исключение subscription
   URL из access logs, перезапуск процесса, резервное копирование и мониторинг review/unsynced.
5. Проверить миграцию на копии БД и план отката. Передать конкретный план развёртывания
   пользователю; текущая задача не разрешает изменения работающего сервера.

Следующая итерация продукта: уведомление до истечения, QR/картинки подключения,
операторский интерфейс сверки review, настройки чеков/возвратов, ограничения частоты
и оптимизация worker при росте числа платежей. Эти пункты не выдаются за завершённые.
